## 前置条件
- 目标环境可访问（基址见 _ENVIRONMENTS.md，默认 test）

## 测试数据
- 起始路径: /
- 搜索关键词: 电视

## 测试步骤
1. 打开海信商城首页
2. 在页面顶部的搜索输入框中输入搜索关键词
3. 按回车提交搜索
4. 等待搜索结果页加载完成

## 预期结果
- 提交搜索后 URL 应进入搜索结果页（路径包含 search，查询串包含搜索关键词）
- 结果页标题应包含“搜索”
- 结果页应展示与关键词相关的商品（页面可见文本中出现关键词）

## 前置条件
- 目标环境 admin-new 可访问（基址见 _ENVIRONMENTS.md）
- 已使用 admin-new 账号登录（凭据见 _CREDENTIALS.md，账号 key: admin-new）

## 测试数据
- 环境: admin-new
- 登录后入口: 顶部菜单“订单管理” → 左侧子菜单“敏感词管理”

## 测试步骤
1. 登录新运营后台（admin-new）
2. 点击顶部菜单“订单管理”
3. 在左侧子菜单中点击“敏感词管理”
4. 等待敏感词管理页面加载完成

## 预期结果
- 页面成功进入敏感词管理（标签页/标题体现“敏感词管理”）
- 敏感词列表区域正常展示（呈现敏感词数据表，含敏感词条目及列表表头）
- 页面无接口错误提示（无“请求失败/加载失败”类报错），非空白页
- 若当前确无敏感词数据，应展示明确的“暂无数据”空状态，而非报错

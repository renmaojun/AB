## 前置条件
- 已登录 admin-new 并进入“服务商品管理”列表页（见 TC-svcprod-001）

## 测试数据
- 环境: admin-new
- 审核状态取值: 审核中 / 审核通过 / 审核驳回

## 测试步骤
1. 在“审核状态”筛选项选择“审核中”，查询，记录结果
2. 重置后选择“审核通过”，查询，记录结果
3. 重置后选择“审核驳回”，查询，记录结果
4. 检查各次结果中商品的审核状态列

## 预期结果
- 审核状态为单选（不能同时选中多个）
- 选择某审核状态后，结果列表中所有商品的审核状态均等于所选值
- 三种状态分别筛选结果互不混入其他状态
- 某状态无数据时展示空状态而非报错

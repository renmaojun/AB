## 前置条件
- 目标环境 admin-new 可访问（基址见 _ENVIRONMENTS.md）
- 已使用 admin-new 账号登录（凭据见 _CREDENTIALS.md，账号 key: admin-new）
- 服务商品后端服务可用（若 503 则判阻塞）

## 测试数据
- 环境: admin-new
- 登录后入口: 顶部菜单“商品中心” → 左侧子菜单“服务商品管理”

## 测试步骤
1. 登录新运营后台（admin-new）
2. 点击顶部菜单“商品中心”
3. 在左侧子菜单中点击“服务商品管理”
4. 等待服务商品管理列表页加载完成

## 预期结果
- 页面正常进入服务商品管理（非错误页/空白页）
- 服务商品列表正常展示（出现列表表格，或在无数据时展示“暂无数据”空状态）
- 筛选控件齐全：商品名称、商品ID/商品型号/物料编码、商品类型（多选）、审核状态（单选）、以及“已上架终端”筛选
- 页面右上角提供“创建服务商品”“多终端上下架”“导出”入口
- 列表请求成功（无“请求失败/加载失败”类报错，可用 network 取证）

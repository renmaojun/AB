## 前置条件
- admin-new 环境可访问

## 测试数据
- 环境: admin-new
- 期望埋点事件: page_view / button_click / filter_apply / export_data

## 测试步骤
1. 未登录状态下直接访问服务商品管理页 URL，观察是否被拦截/重定向到登录页
2. 登录后进入页面（鉴权通过）
3. 进入页面、点击按钮、应用筛选、执行导出，分别用 network requests 观察是否发出对应埋点请求
4. 执行一次导出后，进入操作日志（系统管理/日志相关位置）查看是否记录导出操作人与时间

## 预期结果
- 未登录访问被重定向到登录页（接口鉴权生效，需登录态+权限）
- 登录后可正常访问
- 关键动作触发对应埋点请求：进入页=page_view、点击按钮=button_click、应用筛选=filter_apply、导出=export_data
- 操作日志中可查到本次导出操作，含操作人与时间

## 前置条件
- 已登录 admin-new 并进入“服务商品管理”列表页（见 TC-svcprod-001）

## 测试数据
- 环境: admin-new
- 商品类型取值: 清洗 / 安装 / 延保 / 配辅耗材

## 测试步骤
1. 在“商品类型”筛选项中单选“清洗”，查询，记录结果条数 N1
2. 重置后单选“安装”，查询，记录结果条数 N2
3. 重置后同时多选“清洗”+“安装”，查询，记录结果条数 N3 及命中项类型
4. 对比 N3 与 N1、N2

## 预期结果
- 单选某类型时，结果中商品类型均为该类型
- 多选“清洗”+“安装”时，结果为两类型的并集（OR 逻辑）：结果包含清洗类与安装类商品
- N3 约等于 N1 与 N2 的并集规模（OR，而非 AND 的交集；AND 下通常为空或更少）
- 结果中每条商品的类型属于所选类型集合之一

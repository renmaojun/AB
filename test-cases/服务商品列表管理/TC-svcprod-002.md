## 前置条件
- 已登录 admin-new 并进入“服务商品管理”列表页（见 TC-svcprod-001）

## 测试数据
- 环境: admin-new
- 名称关键词-中文片段: 清洗
- 名称关键词-大小写验证: 小写关键词 与 其大写形式（如 abc / ABC），用于验证不区分大小写

## 测试步骤
1. 在“服务商品管理”列表页的“商品名称”筛选框输入一个名称片段
2. 点击“查询/筛选”
3. 等待结果返回，记录结果条数与命中项
4. 清空后用同一英文关键词的大写形式再次筛选
5. 对比两次结果

## 预期结果
- 筛选结果仅包含“商品名称包含该关键词”的商品（模糊匹配，非精确相等）
- 结果数量相对未筛选时减少或持平，且命中项名称确实包含关键词
- 同一关键词的大写与小写形式筛选结果一致（不区分大小写）
- 若无匹配，展示“暂无数据”空状态而非报错

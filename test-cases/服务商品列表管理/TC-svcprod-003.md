## 前置条件
- 已登录 admin-new 并进入“服务商品管理”列表页（见 TC-svcprod-001）

## 测试数据
- 环境: admin-new
- 取值来源: 从列表现有数据中取一条真实的 商品ID / 商品型号 / 物料编码 的片段作为筛选输入

## 测试步骤
1. 从列表中记录一条真实商品的 商品ID、商品型号、物料编码（多 SKU 的任一编码）
2. 在“商品ID”筛选框输入该 ID 的片段，查询，记录结果
3. 重置后，在“商品型号”筛选框输入型号片段，查询，记录结果
4. 重置后，在“物料编码”筛选框输入某 SKU 的物料编码片段，查询，记录结果

## 预期结果
- 商品ID 片段筛选：结果包含该 ID 对应商品（包含匹配，非必须完整相等）
- 商品型号 片段筛选：结果包含该型号对应商品（包含匹配）
- 物料编码 片段筛选：命中“任一 SKU 的物料编码包含该片段”的商品
- 三类筛选结果均与输入条件相关；无匹配时展示空状态而非报错

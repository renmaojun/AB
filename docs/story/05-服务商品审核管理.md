# 05: 服务商品审核管理（上架审核+价格审核）

**What to build:** 在现有「审核管理」下新增两个审核页。①服务商品上架审核：筛选（服务商品名称/商品型号/物料编码/终端），表格列（勾选框/名称/型号/SKU/终端/操作类型绿胶囊「上架」/提交人/提交时间/审核操作），支持单条通过/驳回与批量通过/批量驳回，驳回必填原因，通过后回调自动上架。②服务商品价格审核：筛选（名称/型号/SKU/变更字段/提交人），表格列（名称/型号/SKU/变更字段/原价格/新价格红字/提交人/提交时间/审核操作），同一商品可同时有「统一零售价」「最低价」两条变更记录，通过后回调新价格生效（版本化审核）。商品下架不需要审核；空状态展示「当前没有审核信息」。

**Blocked by:** 03（价格审核单来源）、04（上架审核单来源）

**Status:** ready-for-agent

**Owners:** 后端 王大冠.ex / 前端 栗浩杰.ex / 测试 张裕.ex（批次 批4，优先级 P0）

**验收标准:**

- [ ] 审核管理下出现「服务商品上架审核」「服务商品价格审核」两个入口页
- [ ] 上架审核：单条「通过」→ 回调该商品对应终端自动上架；「驳回」弹窗必填原因，提交后商品恢复下架态
- [ ] 价格审核：单条「通过」→ 回调新价格生效替换旧价；「驳回」→ 对应行恢复可编辑（重新编辑）
- [ ] 批量通过/批量驳回：勾选多条生效；驳回弹窗原因必填；未勾选时提示先勾选
- [ ] 价格审核页同一商品两条变更记录（统一零售价/最低价）分别展示，新价格红字
- [ ] 时间格式 YYYY-MM-DD HH:MM；操作类型「上架」绿胶囊
- [ ] 无待审核数据时展示空状态「当前没有审核信息」
- [ ] 审核记录与操作日志（审核人/时间/结果/原因）；接口鉴权；通过/驳回回调失败有重试与告警

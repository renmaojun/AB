# 07: 服务订单导出与服务订单报表

**What to build:** 提供服务订单批量导出，两种方式：①服务订单列表页右上角「导出」，按当前筛选条件导出，弹窗确认后跳转导入导出中心下载；②「报表管理 → 常用报表」新增「服务订单报表」瓦片，进入后选时间范围（开始—结束）点击右上「导出」生成报表。导出文件 40+ 字段，含延保特有（sn码/延保商品型号/延保商品品牌/延保商品类别/购机金额/购机时间）与配辅耗材特有（物流状态/物流单号），非对应类型订单留空。

**Blocked by:** 06（订单数据与列表页导出入口）

**Status:** ready-for-agent

**Owners:** 后端 王大冠.ex / 前端 栗浩杰.ex / 测试 吕恒善.ex（批次 批5，优先级 P1）

**验收标准:**

- [ ] 列表页「导出」按当前筛选条件生成导出文件，弹窗确认后跳转导入导出中心
- [ ] 常用报表网格出现「服务订单报表」瓦片，点击进入报表页
- [ ] 报表页时间范围（开始—结束，清除 × 图标）+ 重置/导出按钮
- [ ] 导出字段完整：基础 34 项 + sn码/延保商品型号/延保商品品牌/延保商品类别/购机金额/购机时间（延保）+ 物流状态/物流单号（配辅耗材），非对应类型留空
- [ ] 导出任务异步生成，复用导入导出中心下载；记录操作人和时间
- [ ] 接口鉴权、埋点 export_data（pageName、rowCount）

# 02: 服务商品新建与编辑（ecpx 联动）

**What to build:** 运营人员在商城运营端新建服务商品：输入商品型号（输入联想，数据来自 ecpx 推送至商城数据库），选中后自动带出商品名称、物料编码、物料名称（三者只读）；手动维护类目（一级同家电类目，二级：清洗/安装/延保/配辅耗材，三级级联）、服务类型标记（上门/虚拟/实物耗材/邮寄耗材）、品牌（海信/科龙/容声/ASKO）、款式名称、商品图（批量上传、拖拽排序、首图即主图、≤20 张、单张 ≤20m）、商品视频（≤1 个）、卖点（1~10 个）、商品详情富文本（单图 ≤50m）。一级类目为清洗时增显「清洗服务类型」（全拆/半拆/免拆）。保存时校验物料编码不存在才可创建，成功生成全局唯一商品ID。编辑页复用表单，商品型号/商品名称/物料编码/物料名称不可修改；编辑保存后商品自动下架并重新走审核流程。

**Blocked by:** 01（列表页提供创建/编辑入口）

**Status:** ready-for-agent

**Owners:** 后端 孙逊.ex / 前端 栗浩杰.ex / 测试 张裕.ex（批次 批1，优先级 P0）

**验收标准:**

- [ ] 输入型号有联想，选中后带出商品名称、物料编码、物料名称且三者只读（物料编码来自 ecpx 同步，不可手动增删）
- [ ] 必填校验齐全：商品型号/名称/简称/三级类目/服务类型标记/品牌/商品图/卖点/商品详情
- [ ] 物料编码已存在时创建失败并提示「不能创建」；不存在时创建成功并生成全局唯一商品ID
- [ ] 商品图批量上传、拖拽排序、第一张为主图封面、上限 20 张、单张 ≤20m 超限拦截
- [ ] 卖点至少 1 个最多 10 个，超限拦截；商品详情单图 ≤50m
- [ ] 一级类目=清洗时展示清洗服务类型（全拆/半拆/免拆）并必填
- [ ] 编辑态：商品型号/商品名称/物料编码/物料名称禁改，其余可改
- [ ] 编辑保存成功后商品自动下架并进入重新审核流程（前端有提示）
- [ ] 文件上传前后端双重格式校验；操作日志记录操作人和时间；接口鉴权

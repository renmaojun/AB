# 08: 支付时间设置（支付超时自动关闭）

**What to build:** 服务订单管理页右上角提供「支付超时设置」入口（时钟图标）。弹窗说明「设置待支付订单的自动关闭时间，超过设定时间未支付的订单将自动关闭」，展示当前设置提示（「当前设置：买家下单后超过 X 分钟未支付，订单将自动关闭。建议设置 15~60 分钟。」），输入超时时间（分钟，必填），保存后配置生效。后端定时任务扫描待支付订单，下单时间超过配置值的自动关闭（关闭原因：超时关闭），与手动关闭并发时状态流转幂等。

**Blocked by:** 06（设置入口位于服务订单管理页，作用于待支付订单）

**Status:** ready-for-agent

**Owners:** 后端 邵明阳.ex / 前端 栗浩杰.ex / 测试 吕恒善.ex（批次 批5，优先级 P1）

**验收标准:**

- [ ] 弹窗展示当前设置值与建议范围（15~60 分钟）提示
- [ ] 超时时间必填、正整数校验；为空/非法输入拦截
- [ ] 保存设置成功 → 配置生效、弹窗关闭、记录操作人和时间（操作日志）
- [ ] 定时任务：下单超过配置时长的待支付订单自动关闭，关闭原因=超时关闭
- [ ] 未超时订单不受影响；超时关闭与手动关闭并发幂等（先到者生效）
- [ ] 超出 15~60 建议范围是否强制拦截、存量待支付订单是否回溯——口径待产品确认（U7）
- [ ] 接口鉴权、埋点 button_click（保存设置）

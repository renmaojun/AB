# 01: 服务商品列表管理（搜索/筛选/展示/导出）

**What to build:** 商城运营端新增「服务商品管理」列表页。运营人员可进入该页，按商品名称（模糊、不区分大小写）、商品ID/商品型号/物料编码（包含匹配）、商品类型（多选 OR）、审核状态（单选）组合筛选服务商品；列表展示商品名称、类型徽章、型号、商品ID、物料编码（多 SKU）、SKU数、最近修改时间、审核状态、修改人，行内提供「编辑」入口；右上角「导出」弹出确认弹窗后跳转导入导出中心下载含 18 个字段的商品数据文件。页面右上角另提供「创建服务商品」与「多终端上下架」入口（跳转后续 story）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Owners:** 后端 孙逊.ex / 前端 栗浩杰.ex / 测试 张裕.ex（批次 批1，优先级 P0）

**验收标准:**

- [ ] 进入服务商品管理页，加载全部服务商品列表及全部筛选控件（含原型中的「已上架终端」筛选，口径经产品确认）
- [ ] 商品名称模糊匹配不区分大小写；商品ID/商品型号包含匹配；物料编码任一 SKU 包含匹配
- [ ] 商品类型多选按 OR 逻辑过滤（清洗/安装/延保/配辅耗材）
- [ ] 审核状态单选过滤（审核中/审核通过/审核驳回）
- [ ] 商品类型徽章色：清洗-浅蓝、延保-绿、配辅耗材-粉、安装-灰；物料编码列多行展示
- [ ] 点击「编辑」跳转商品编辑页并正确带出商品信息（见 02）
- [ ] 点击「导出」弹「文件下载中」弹窗（取消/确定），确定后跳转导入导出中心
- [ ] 导出文件包含 18 个字段：商品ID、型号、skuID、sku编码、统一零售价、最低价、品牌、商品名称、一级类目、子类目名称、商品状态、审核状态、商品上架终端、商品类型、服务类型、创建时间、最后修改时间、商品链接
- [ ] 筛选结果为空展示空状态；筛选/重置按钮行为正确
- [ ] 操作日志记录导出操作人和时间；接口鉴权（登录态+权限）；埋点 page_view/button_click/filter_apply/export_data

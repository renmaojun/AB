# 04: 服务商品多终端上下架管理

**What to build:** 商城运营端新增「服务商品多终端上下架管理」页，以「商品×终端」为粒度管理服务商品在商城小程序/H5/爱家APP/爱家小程序的上架与下架（终端枚举待产品确认 U3，原型出现「商城PC端」）。筛选：商品名称/型号（模糊）、物料编码（包含）、状态（全部/已上架/下架）、终端（单选）。列表展示商品名称、型号、物料编码、终端、状态徽章、审核状态，行内操作按状态渲染：已上架→「下架」；下架（无记录/通过/驳回）→「上架」；下架（审核中）→「查看流程/撤销申请」。支持批量上架（绿）/批量下架（红）。上架提交审核（审核通过自动上架），下架无需审核直接执行；确认弹窗文案「将对选中的 N 项提交上架审批，审核通过后自动上架」/「将对选中的 N 项执行下架操作（无需审批）」。上架前校验全部 SKU 价格已维护且审核通过，否则拦截提示。商品创建后默认下架；编辑后自动下架重新审核。

**Blocked by:** 01（页面入口）、02（商品数据）、03（SKU 价格数据供上架校验）

**Status:** ready-for-agent

**Owners:** 后端 王大冠.ex / 前端 栗浩杰.ex / 测试 张裕.ex（批次 批3，优先级 P0）

**验收标准:**

- [ ] 商品创建后默认「下架」；每个「商品×终端」组合一行
- [ ] 下架行点「上架」：价格校验通过后弹确认弹窗，提交审批，审核状态变「审核中」，操作列显示查看流程/撤销申请
- [ ] 审核中「撤销申请」→ 恢复下架并重新显示上架按钮；审核通过回调 → 自动上架显示下架按钮
- [ ] 已上架行点「下架」→ 确认弹窗 → 直接下架（无需审核）
- [ ] 批量上架/批量下架：勾选多行，确认弹窗 N 项文案正确，批量上架逐项走审核、批量下架直接执行
- [ ] 上架校验：遍历全部 SKU，存在价格未维护或价格审核非通过 → 拦截并提示「请先维护 xxxxxxx 商品价格」/「存在SKU价格未维护」
- [ ] 状态徽章色：已上架绿、下架红、审核通过绿、审核中黄、无记录 —
- [ ] 版本化审核：编辑提交审核期间旧状态继续生效，通过后新状态替换
- [ ] 操作日志、接口鉴权、埋点 page_view/button_click/filter_apply

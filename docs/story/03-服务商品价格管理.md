# 03: 服务商品价格管理（展示/修改/导入/导出）

**What to build:** 商城运营端新增「服务商品价格管理」页，按物料编码（SKU）粒度管理统一零售价与最低价：支持按商品名称（模糊）、物料编码/商品ID/商品型号（包含）、商品类型（单选）、审核状态（全部/已生效/审核中/已驳回）筛选；列表展示商品名称、类型彩标、型号、物料编码、统一零售价（红字加粗）、最低价、审核状态标签、最近修改、修改人，操作列按状态显示「修改价格/撤回/重新编辑」。修改价格弹窗（只读商品信息+可编辑双价格）提交后进入审核中并锁定；批量导入走三步弹窗（下载模板→填写→上传 .csv/.xlsx，以商品ID为唯一依据，失败返回原因及商品ID，导入价格同样提交审核）；导出跳转导入导出中心（15 字段）。所有价格变更须经审核生效，审核期间旧价继续生效（版本化审核）。

**Blocked by:** 02（商品与 SKU 数据存在）

**Status:** ready-for-agent

**Owners:** 后端 王大冠.ex / 前端 栗浩杰.ex / 测试 吕恒善.ex（批次 批2，优先级 P0）

**验收标准:**

- [ ] 六项筛选组合生效；审核状态过滤含已生效/审核中/已驳回
- [ ] 列表样式：统一零售价红字加粗、最低价 ¥X.XX 或 —、审核状态徽章色（通过绿/审核中黄/驳回红）
- [ ] 修改价格：校验统一零售价 ≥ 最低价、最多 2 位小数、审核中不可编辑；提交后生成审核单并锁定价格字段
- [ ] 审核中行操作显示「撤回」；驳回行显示「重新编辑」；已生效行显示「修改价格」
- [ ] 批量导入：模板字段商品ID/型号/skuID/sku编码/统一零售价/最低价；以商品ID为唯一依据；失败行返回失败原因+商品ID；成功行进入审核
- [ ] 导入文件仅 .csv/.xlsx；统一零售价必填、最低价选填（口径以原型弹窗为准，待产品确认 U5）
- [ ] 导出文件含 15 字段：商品ID、型号、skuID、sku编码、统一零售价、最低价、审核状态、品牌、商品名称、一级类目、子类目名称、商品状态、商品上架终端、最后修改时间、商品链接
- [ ] 版本化审核：审核通过后新价替换旧价生效
- [ ] 操作日志、接口鉴权、埋点 price_audit_submit/price_audit_withdraw/import_data/export_data

## Issues

### ISSUE-001：佣金发放审核「审核通过」提交后状态未变更且无失败提示（待确认后端拒绝/前端缺陷）

| 字段 | 值 |
|------|-----|
| 严重级别 | medium（待确认，可能升级） |
| 分类 | functional / ux |
| URL | /o2o/commission-audits |

**描述**

对待审核任务 538"春苗测试发放1"（汇总金额 ¥-4.54，负数）执行"审核→审核通过→二次确认确定"后，确认弹窗关闭，但列表中该任务**审核状态仍为"待审核"**（snapshot 复核确认），未流转为"审核通过"，且页面**未出现明显的成功或失败提示**。二次确认文案提示"校验发佣账户余额，余额不足时将被拒绝；操作成功后该任务不可再次审核"。

**疑似原因（待取证确认）**
- 可能后端因发佣账户余额校验失败（或负数金额非法）拒绝了提交——属正常业务拦截，但**前端缺少明确的失败原因提示**（UX 缺陷）
- 也可能是提交请求未正确发出/响应处理有误（功能缺陷）

**待确认**：需用 `network requests` 取证审核接口（提交时的 POST 请求）返回状态码与响应体，区分"后端业务拒绝"与"前端提交缺陷"。因本轮 daemon 不稳定未能完成接口取证。建议复测时优先对正数金额任务（如 407"测试发放"¥8.73）重试，并抓接口。
